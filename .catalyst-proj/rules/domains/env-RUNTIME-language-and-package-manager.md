## Scope

Which language, runtime version, and package manager each of correlator's
two components (`server/`, the Python Sump; `app/`, the Electron/React
client) is built on. Deliberately scoped to the language/tooling baseline
only — the specific application frameworks built on top (Electron, React,
Jotai, electron-builder) are documented product-stack decisions (see
`docs/roadmap/cttc-to-correlator-port.md` §4) that get added to `app/`'s
dependencies when Phase 4 of that roadmap actually starts building the
app shell, not part of this greenfield tooling pass.
