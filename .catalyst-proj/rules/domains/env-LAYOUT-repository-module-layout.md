## Scope

The top-level directory convention the repository follows. Departs from
cttc's own layout (which nested its server as `app/server-logsump/`)
because the Sump is now a first-class, independently-deployable,
potentially-remote service (secondary-Sump federation, per
`docs/roadmap/cttc-to-correlator-port.md` §7) rather than a sub-component
of the Electron app — nesting it under `app/` would misrepresent that.
