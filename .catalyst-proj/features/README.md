# `features/`

Non-rule-linked, non-measured roadmap ideas (`FEAT-NNNN`) — see
`rules/Rules-of-Rules.md` §9. Never itself implemented; when work on one
starts, open a `REQ-NNNN` in [`../requirements/`](../requirements/) instead.

- [`TEMPLATE-FEATURE.md`](TEMPLATE-FEATURE.md) — the template for every new
  feature entry.
- [`features.md`](features.md) — the index of every feature entry that
  exists.
