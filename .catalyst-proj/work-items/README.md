# `work-items/`

The agile process layer (epics → stories → tasks/spikes/sprints) sitting
above the rule-linked artifacts in [`../requirements/`](../requirements/)
and [`../development/`](../development/). See
[`rules-of-work-items.md`](rules-of-work-items.md) for the standards
governing this layer.

- `epics/` / [`epics.md`](epics.md) / [`TEMPLATE-EPIC.md`](TEMPLATE-EPIC.md)
- `stories/` / [`stories.md`](stories.md) / [`TEMPLATE-STORY.md`](TEMPLATE-STORY.md)
- `tasks/` / [`tasks.md`](tasks.md) / [`TEMPLATE-TASK.md`](TEMPLATE-TASK.md)
- `spikes/` / [`spikes.md`](spikes.md) / [`TEMPLATE-SPIKE.md`](TEMPLATE-SPIKE.md)
- `sprints/` / [`sprints.md`](sprints.md) / [`TEMPLATE-SPRINT.md`](TEMPLATE-SPRINT.md)

correlator uses Scrum vocabulary by default; switch to Kanban or a hybrid
at any time per `rules-of-work-items.md`'s header note without changing
anything below this layer.
